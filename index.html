🧠 Como a lógica funciona?

1. Plano
Cada dia possui uma lista de exercícios e uma quantidade de séries. Você pode trocar exercícios, adicionar novos ou alterar o número de séries.
2. Registro
Ao preencher carga, repetições e RIR, o sistema guarda o rascunho no navegador usando localStorage. Você não precisa de banco de dados para usar.
3. Finalização
Ao finalizar, somente as séries preenchidas ou marcadas como concluídas entram no histórico. O rascunho daquele dia é limpo para o próximo treino.
4. Biblioteca
A biblioteca usa os exercícios cadastrados no JavaScript. Cada exercício possui grupo muscular, faixa de repetições, descrição detalhada de execução e duas opções de variação/substituição.
5. Fotos
As páginas de execução usam imagens externas da internet como referência visual. Se uma imagem não carregar, o texto de execução continua disponível.
